此 **Manta 企业数据集样本**包含 **1,547 条记录**，并使用 **Bright Data API** 提取。

## 数据点

| 字段名称 | 描述 |
|------------|-------------|
| `company_name` | 企业实体的官方名称。 |
| `business_state` | 企业注册或运营所在的州。 |
| `sic_code` | 用于表明企业类型的标准行业分类代码。 |
| `phone_number` | 企业的联系电话。 |
| `website` | 企业的官方网站 URL。 |
| `business_categories` | 用于定义企业活动和所属行业的类别。 |
| `business_city` | 企业所在的城市。 |
| `business_country` | 企业所在的国家/地区。 |
| `business_zip_code` | 企业所在地的邮政编码。 |
| `closed_on` | 表明企业是否已停止营业（如适用）。 |
| `opening_hours` | 企业每天开始营业的时间。 |
| `closing_hours` | 企业每天结束营业的时间。 |
| `latitude` | 企业所在地的地理纬度坐标。 |
| `longitude` | 企业所在地的地理经度坐标。 |
| `location_type` | 企业场所的类型，例如零售店、办公室。 |
| `year_established` | 企业成立的年份。 |
| `avg_opening_hour` | 企业通常开始营业的平均时间。 |
| `avg_closing_hour` | 企业通常结束营业的平均时间。 |
| `business_street_name` | 企业所在地的街道地址。 |
| `description` | 企业及其运营情况的简要概述。 |
| `services` | 企业提供的服务列表。 |
| `links` | 与企业相关的其他链接（如有）。 |
| `estimated_annual_revenue` | 企业产生的估算年收入。 |
| `num_employees` | 企业的员工人数。 |
| `review_count` | 企业收到的评论总数。 |
| `reviews` | 客户对企业的评论和反馈。 |
| `owner` | 企业所有者或主要联系人的姓名。 |
| `manta_link` | Manta 平台上的企业资料 URL。 |
| `url` | 与企业相关的通用 URL。 |
| `company_id` | 数据集中企业的唯一标识符。 |


## 用例

### 1. 市场分析
利用该数据集识别市场趋势和行业基准，为战略规划和决策提供支持。

### 2. 业务拓展
利用企业详细信息发现潜在合作伙伴或客户，拓展人脉与增长机会。

### 3. 竞争情报
分析竞争对手信息，深入了解其运营和市场定位，从而改进竞争策略。



## 文件格式

该数据集提供多种格式：
- **CSV**（本样本中包含）
- **JSON**
- **NDJSON**
- **JSON Lines**
- **Parquet**
- **压缩文件 (.gz)**
